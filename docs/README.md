\# 字源库 · 光库



这是“光通启明”项目的汉字字源数据库。



\## 存储格式

\- 每个汉字一个 JSON 文件，按拼音首字母分文件夹

\- 或者一个大的 CSV 表（初期推荐）



\## 字段说明

\- 汉字：当前字符

\- 拼音：标准读音

\- 部首：所属部首

\- 笔画：笔画数

\- 甲骨文：对甲骨文字形的描述

\- 金文：对金文字形的描述

\- 小篆：小篆字形描述

\- 本义：最早的含义

\- 现代常用义：今天的主要用法

\- 文化关联：相关的汉字、典故、词语

\- 羲和视角：羲和会如何向用户解读这个字
