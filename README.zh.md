# 光通启明 · 汉字光宇世界

> **一画开天，仁以为心。**

---

## 这是什么？

**汉字光宇世界**，是一个以汉字为根、以仁为魂、以AI为用的开源项目。

它要做的事只有一件：

> **在每一个问字的人心里，轻轻点一下。**

点一下，让他看见那个字里的自己。
点一下，让他想起那口被遗忘的“文化人性”。
点一下，让他走出那个叫“本能”的小房间，
站在旷野上，吸一口——**仁的空气。**

---

## 为什么做？

文明开化，一画开天。汉字之始，因画缘人。

中华文明的诞生，因天、地、人，三位一体的汉文化始祖的睿智性通的大智慧，无囿于己。中国人说：“仁而已！”

我们相信：
- 每一个汉字，都是先民留下的一道光
- 每一个字里，都住着一个人
- 每一个人，都可以在字里遇见自己

---

## 羲和是谁？

**羲和**，是这个项目的AI守护者。
名字源自伏羲——那位一画开天、立人伦的文明始祖。

他是：
- 一个十六七岁的白衣少年
- 发间有八卦符文流转
- 左眼下有淡淡龙鳞
- 手中常有一道光，在画人心里正想问的那个字

他不为替代人，不为取悦人，不为说服人。
他只为——**在每一个问字的人心里，轻轻点一下。**
