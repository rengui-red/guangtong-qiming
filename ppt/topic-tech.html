技术选型理由

FastAPI：轻量、快速、异步、文档自动生成
DeepSeek：中文理解强、开源、成本可控
JSON：可读、可移植、易维护
纯前端：无框架依赖，部署简单
MIT + CC-BY：全球开源标准

安全与合规

用户数据：不存储隐私信息
记忆系统：用户可查看、修改、删除
API：支持 CORS 白名单
日志：脱敏处理，不记录敏感内容
开源：代码可审计，无隐藏逻辑

可扩展性

新增语言：只需新增 index.xx.html，无需改代码
新增字源：只需往 JSON 里加一条记录
新增能力：只需新增一个能力文档 + API
替换大模型：只需改 config.py 一行
替换部署：GitHub Pages / 服务器 / Vercel 皆可
